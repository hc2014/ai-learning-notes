# tensorflow_boston.py 业务流程梳理

## 1. 这个脚本在做什么

这个脚本是一个典型的“机器学习回归任务”示例，目标是使用 Boston 房价数据集训练一个神经网络模型，用来预测房屋价格。

它的核心业务场景可以理解为：
- 输入一组房屋特征
- 模型输出一个房价预测值
- 通过训练和测试，验证模型是否能够较好地拟合房价规律

在实际业务中，这类方法可用于：
- 房屋估价
- 房地产价格评估
- 金融风控中的资产估值辅助
- 价格预测类场景的建模原型

## 2. 业务流程拆解

### 2.1 数据加载
脚本首先从 housing.csv 文件中读取数据。

- 文件没有表头
- 使用空格分隔
- 数据包含 13 个特征列和 1 个目标值列

这一步相当于把“原始业务数据”导入到程序中，准备后续训练。

### 2.2 特征与标签分离
代码将前 13 列作为输入特征 X，将最后 1 列作为目标值 y。

- X：房屋的各种特征，例如房屋面积、房间数、交通便利性等
- y：房屋价格，也就是需要预测的目标值

### 2.3 调整标签维度
由于神经网络训练时通常希望标签是二维数组，所以把 y 从一维数组转成二维数组：

- 由形状 (n,) 变成 (n, 1)

这样更适合 Keras 模型训练。

### 2.4 数据归一化
脚本使用 MinMaxScaler 对输入特征进行归一化处理。

原因是：
- 神经网络对输入数据的尺度比较敏感
- 如果特征值差异很大，训练过程会变得不稳定
- 归一化可以让模型更快更稳地收敛

### 2.5 划分训练集和测试集
使用 train_test_split 将数据划分为：
- 训练集：用于让模型学习规律
- 测试集：用于评估模型在未见过数据上的表现

这里使用了 25% 的数据作为测试集。

### 2.6 构建神经网络
使用 TensorFlow Keras 的 Sequential API 构建一个简单的全连接神经网络。

网络结构如下：
- 第一层 Dense(10, activation='relu')
  - 输入维度是 13
  - 10 个神经元
  - 使用 ReLU 激活函数
- 第二层 Dense(1)
  - 输出一个预测值，也就是房价

这是一种典型的回归神经网络结构。

### 2.7 编译模型
模型编译时指定了：
- 优化器：Adam
- 学习率：0.01
- 损失函数：MSE（均方误差）

对于房价预测这种连续值回归任务，MSE 是非常常见的损失函数。

### 2.8 训练模型
脚本使用 300 个 epoch 进行训练。

训练期间，模型会不断调整权重，使预测值越来越接近真实房价。

### 2.9 评估与可视化
训练结束后，脚本做了两类结果展示：

1. 损失曲线
   - 观察训练过程中损失是否下降
   - 判断模型是否在学习

2. 预测结果对比图
   - 将测试集的真实值和预测值绘制为散点图
   - 直观判断模型效果

### 2.10 保存模型
最后将模型和归一化器保存下来：
- 模型文件：boston_model.keras
- 标准化器文件：scaler.pkl

这样训练好的模型可以在后续直接加载用于预测新数据。

## 3. 主要技术点

### 3.1 Python 数据处理
- 使用 pandas 读取和处理表格数据
- 使用 numpy 进行数组运算和形状调整

### 3.2 数据预处理
- MinMaxScaler：对特征做归一化
- train_test_split：切分训练集和测试集

### 3.3 TensorFlow / Keras 神经网络
- Sequential：顺序模型构建方式
- Dense 层：全连接层
- ReLU 激活函数：增加非线性表达能力
- Adam 优化器：高效优化参数
- MSE 损失函数：用于回归问题

### 3.4 模型训练与评估
- fit：训练模型
- predict：对新样本进行预测
- matplotlib：绘制损失曲线和预测对比图

### 3.5 模型持久化
- model.save：保存训练好的神经网络
- pickle.dump：保存标准化器，确保后续预测时使用同样的预处理方式

## 4. 代码中各部分是如何在业务中使用的

### 4.1 数据输入阶段
在真实业务中，输入数据通常是某个样本的房屋特征，例如：
- 房屋面积
- 房间数量
- 年龄
- 教育水平
- 交通便利性
- 社区环境等

这些特征经过模型后，就能得到一个估价结果。

### 4.2 训练阶段
训练阶段相当于“建立估价经验”过程。

模型通过历史房价样本，不断学习：
- 哪些特征更重要
- 特征之间如何共同影响价格
- 哪种组合更可能带来更高房价

### 4.3 预测阶段
训练完成后，模型可以对新的房屋样本进行估价。

例如：
- 输入一套新的房产特征
- 模型输出一个预测价格
- 企业可以用它辅助定价、评估或决策

### 4.4 生产部署思路
训练完成后，通常不会再重新训练，而是直接加载模型进行推理。

这也是脚本最后保存模型文件和标准化器文件的意义：
- 模型文件负责“计算能力”
- 标准化器文件负责“输入格式一致性”

只有两者配合使用，预测结果才有意义。
