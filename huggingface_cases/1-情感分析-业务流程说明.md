# 情感分析示例业务流程说明

## 一、整体业务流程

本示例是一个“中文文本情感分析”应用，核心目标是：

- 输入一段中文评论文本
- 通过本地已经下载好的模型进行情感分类
- 输出该文本属于“正向情绪”还是“负向情绪”的预测结果
- 同时给出模型的置信度（score）

### 具体执行流程

1. 加载本地模型路径
   
   - 代码中使用 `pipeline(task="sentiment-analysis", model=local_model_path)` 创建分类器。
   - 这里的 `task` 表示任务类型，是“情感分析”。
   - `model` 则指定本地模型目录路径，这样可以实现离线推理。

2. 输入待分析文本
   
   - 示例文本包括：
     - “这个手机屏幕太烂了，反应很慢！”
     - “物流很快，包装很精美，五星好评。”

3. 模型进行推理
   
   - `classifier(text)` 会把文本经过 tokenizer 编码、模型推理后输出分类结果。
   - 模型返回的是一个列表，列表里的每一个元素都是一个预测结果字典。

4. 输出结果
   
   - 输出结构类似：
   
   ```python
   [{'label': 'negative (stars 1, 2 and 3)', 'score': 0.9923227429389954}]
   ```
   
   说明：
   
   - `label`：预测类别
   - `score`：置信度，数值越接近 1，表示模型越确定

---

## 二、当前使用的模型

本示例使用的是：

- `uer/roberta-base-finetuned-dianping-chinese`

对应本地目录：

- `local_models/roberta-base-finetuned-dianping-chinese`

### 模型定位

它属于“中文 RoBERTa-base 文本分类微调模型”，具体是：

- 基座模型：RoBERTa
- 训练任务：文本分类
- 细粒度场景：点评类评论情感分析

### 模型来源说明

从本地模型说明文档可知，该模型是基于 UER-py 工具链进行微调得到的中文分类模型，训练数据来自 Dianping 用户评论数据集。

这个模型的标签定义在其配置文件中：

- `negative (stars 1, 2 and 3)`
- `positive (stars 4 and 5)`

也就是说，它并不是简单的二分类 `positive / negative`，而是更贴近“评论星级”的情感标签：

- 1~3 星视为负面
- 4~5 星视为正面

---

## 三、模型架构和配置特征

从本地配置文件可以看出，该模型的核心架构是：

- `BertForSequenceClassification`

主要配置特征：

- `model_type = bert`
- `hidden_size = 768`
- `num_hidden_layers = 12`
- `num_attention_heads = 12`
- `vocab_size = 21128`

这说明它采用的是 BERT/RoBERTa 风格的编码器，后接分类头，适合做句子级情感分类。

## 四、输入输出示例

### 示例 1：负面评论

输入：

```python
"这个手机屏幕太烂了，反应很慢！"
```

输出：

```python
[{'label': 'negative (stars 1, 2 and 3)', 'score': 0.9923227429389954}]
```

解释：

- 模型把这段文本判断为负面情绪
- 置信度约为 99.23%

### 示例 2：正面评论

输入：

```python
"物流很快，包装很精美，五星好评。"
```

输出通常会是：

```python
[{'label': 'positive (stars 4 and 5)', 'score': 0.99}]
```

解释：

- 模型把这段文本判断为正面情绪
- 置信度通常也会很高

---

### 示例 3：不太准确的

输入：

```
你看你一天天的，就知道吃。
```

输出:

```
[{'label': 'positive (stars 4 and 5)', 'score': 0.93}]
```

解释：

* 这里模型是误判了，需要训练模型，以适应汉语中一些有特殊含义的语句

1. 自动识别用户评论的情绪倾向
